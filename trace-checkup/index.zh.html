去哪训，日志够做什么

只有对话和工具调用的日志，就够照着成功的例子训练。按试错和奖励训练还需要一个给每次尝试打分的办法：提供这种训练的平台都要求有。

怎么收集日志，才答得出来

一份有用的日志该记的十一样东西。报告会给每一样标上记了、记了一部分、没记。

最常缺的：每个操作返回了什么、任务名、成没成。

  • 1每次对话的编号，以及每一步的先后顺序
  • 2每个操作：用了哪个工具、发给它什么
  • 3每个操作原样返回的内容，出错和空结果也要
  • 4任务名：同一类事每次都用同一个名字
  • 5每次对话成没成功：是或否，或 0 到 1 的分数，以及是谁判的（运行时的自动检查，还是事后的人）
  • 6对方对 agent 说的每一句，第一句和后面补充的
  • 7同一个任务至少试 8 次，每次都标成功或失败
  • 8每次对话里 agent 当时拿到的指令（系统提示）和工具清单，以及每个工具需要什么
  • 9跑这次对话的 AI 模型（和版本）
  • 10每次对话用了多少 token（输入和输出）
  • 11可选：agent 开始前、它要处理的那些记录的一份副本

记多少

  • 每个任务试 8 次，每次标成功或失败：这样才看得出多试几次已经能修好多少。
  • 训练之前，大约 5,000 次成功的对话，每次都写明是谁判的成功。少于这个数，已发表的结果有变好也有变差（MUA-RL，arXiv 2508.18669；ToolRL，arXiv 2504.13958）。我们看不出你的会往哪边走。
  • 很多不同的任务，比几个任务的大量重复说明得更多。
看出处

每一句话要么来自你自己日志上的一个读数，要么来自一篇已发表的结果，并写明是哪篇论文。依据不够时，报告会直接说看不出。

从设计上保护隐私

  • 它在你的电脑上运行，不会把任何东西上传给我们或别人。
  • 日志一读进来，这些会被隐藏：邮箱、大多数卡号、常见的密钥，以及“password:”后面的第一个词。电话号码只有按常见写法写时才会被隐藏，例如 +44 20 7946 0958、(415) 555-0132、13812345678——不是每个都会，其余的请自己先藏好。人名和地址不会被隐藏。
  • 它只读你给的那个文件，而且不会改动它。

常见问题

你们会替我们训练模型吗？

如果你愿意：在你选的训练平台上、用你自己的账号（即将推出）。该说别训的时候，我们照样会说。

训练平台给你们钱吗？

不给。我们不卖训练也不卖算力，没有哪个平台付钱给我们。所以报告才能告诉你别训。

预测有多准？

它只给方向和范围，从不给一个确切的数。每张卡都写明有多可靠、依据是什么、什么会推翻它；依据太少就说看不出。

“同样的花费”是什么意思？

让 agent 一个任务多试几次直到成功，要多用几次尝试。报告在你的日志上数出平均要试几次，再拿训练和它比：一次对这么多次。如果日志记了 token，还会写出一次尝试大约用多少 token。在这个网站上按钱比：即将推出。

什么时候不能多试几次？

agent 运行时分不出这次失败了，或者它的操作会改记录、做两次会出事（比如退两次款）。报告会就这两点问你。

我的日志需要记些什么？

每一次对话、agent 做的每个操作和返回的结果；最好还有任务成没成、是谁判的。报告会列出缺了什么。

谁能看到我的日志？

没有人。它在这台电脑上读，不会发到任何地方。
